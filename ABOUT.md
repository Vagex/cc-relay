# Project About

## GitHub Description

FastAPI + Vue relay for routing Codex/Responses API requests to OpenAI-compatible local and cloud LLM providers.

## Longer Summary

Codex Web Relay is a local web console and API adapter that lets Codex use different OpenAI-compatible model providers through one local endpoint. It manages provider profiles in the browser, syncs the active profile to a FastAPI relay process, converts Responses-style requests into chat-completions requests, and preserves streaming output plus function/tool calls.
